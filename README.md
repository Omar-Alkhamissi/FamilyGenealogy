# FamilyGenealogy

FamilyGenealogy is a SQL Server database script for modeling family relationships and genealogy data. It provides schema and sample data for exploring relationship queries.

## Features

- Relational model for people and family connections
- Seed data for query testing
- Single setup script for local SQL Server execution

## Tech Stack

- Microsoft SQL Server
- T-SQL

## Getting Started

Open `FamilyGenealogy.sql` in SQL Server Management Studio or Azure Data Studio and run it against a SQL Server instance where you have database creation permissions.

## Project Structure

- `FamilyGenealogy.sql`: schema and data script
